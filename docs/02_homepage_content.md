## Section I: Frequently Asked Questions (FAQ)

### 1. What is PeopleOps Intelligence?
PeopleOps Intelligence is a centralized [centralised] workforce intelligence and operations platform developed by Codework. It aggregates data from your existing attendance systems, HR records, Microsoft Teams, and GitHub into unified, KPI-driven dashboards for leadership and management review.

### 2. Which business tools and platforms does PeopleOps integrate with?
PeopleOps supports integrations across your core operating stack:
* **HR & Attendance:** GreytHR and biometric hardware check-in systems.
* **Collaboration & Communication:** Microsoft Teams presence and activity.
* **Software Development:** GitHub repositories, pull requests, and commit workflows.
* **Work Management & Files:** Microsoft Planner, Microsoft Calendar, SharePoint, and Worklogix via the Microsoft Graph services layer.

### 3. How does PeopleOps differ from employee monitoring or "bossware" tools?
PeopleOps is built strictly for management review and operational planning. It **does not** log keystrokes, capture desktop screenshots, record webcams, or track personal browsing. Instead, it aggregates high-level, business-approved metadata (e.g., project milestones, attendance logs, and pull request reviews) to help leaders rebalance workloads and support teams fairly.

### 4. Can PeopleOps make automated disciplinary or employment decisions?
No. A foundational business rule of PeopleOps is that insights strictly inform human review. The software cannot and will not trigger automated warnings, salary deductions, disciplinary penalties, or termination decisions.

### 5. Who inside our company can see workforce and employee data?
Access is strictly managed via Role-Based Access Control (RBAC). Department leads, project managers, HR directors, and C-level executives receive access rights tailored specifically to their verified responsibilities. Every view of sensitive information is recorded in traceable audit logs.

### 6. What happens if an integrated tool goes offline or data is incomplete?
PeopleOps features dedicated Integration Health Monitoring and Insufficient Data Handling rules. If a source system fails to sync or an employee's records are incomplete, the platform clearly highlights the missing data rather than displaying inaccurate KPI scores or guessing performance.

### 7. How does PeopleOps match an employee’s identity across different tools?
PeopleOps uses approved organizational [organisational] matching rules to reconcile identities. For instance, it links a team member’s official HRMS profile with their corporate email, Microsoft Teams account, and GitHub handle into one verified profile.

### 8. What is "Ask Tara"?
"Ask Tara" is PeopleOps' built-in conversational query assistant. It allows authorized managers to ask natural-language questions about team KPIs, project statuses, and attendance (such as *"Show me active projects behind schedule this month"*) and returns immediate, contextual answers within approved data boundaries.
